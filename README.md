<h3>Возможности:</h3>
<h4>Дашборд: </h4>
  - Отображение количества оборудования
  - Отображение количества складов
  - Отображение перемещений оборудования
<h4>Вкладка оборудования:</h4>
  - Поиск, учет, добавление оборудования в базу данных, а также установка статуса и назначение инвентарного, серийного номеров.
<h4>Вкладка складов:</h4>
   - Отображение складов и наличие оснащения в них.
		<h5>Вкладка перемещений:</h5>
   - Позволяет отслеживать последние изменения в движении материально-технических средств между складами.
	Включает в себя название оборудования, штрихкод на основе инвентарного номера, перемещение откуда и куда, а также, ФИО ответственного, который назначил перемещение оборудования.
<h5>Вкладка сканера:</h5>
   - Позволяет быстро найти оснащение при помощи сканирования штрихкода с камеры устройства, либо вручную при вводе инвентарного номера вручную.


<h2>ВАЖНОЕ:</h2>
- Штрихкод в системе указывается в формате (ABC-abc-1234)
 - При смене статуса оборудования нужно СНАЧАЛА написать комментарий, а уже потом менять статус оборудования чтобы комментарий отображался
 - Иногда при добавлении оборудования может вылезать ошибка добавления оборудования, но по факту, оно уже есть и добавилось в базу (такое возникает при неверном указании штрихкода, или карточки оборудования в целом.
